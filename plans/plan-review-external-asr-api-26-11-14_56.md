## 核心判断

## 复核记录

- 本轮复核 `README.md`、`docs/web-contract.md`、`asr/web/__init__.py`、`asr/postprocess.py`、`scripts/api_client_example.py` 和 `tests/test_api_transcribe.py`。工作树中已有的计划文件独立于这些改动。
- 静态检查发现，本地路径入口可由通过认证的远程调用者访问，源媒体所有权与上传任务混用。无效配置在后台领取任务后才报错，任务会留在 `running`。同步接口缺格式时可能仍返回 `done`，客户端会创建或截断空字幕文件；同步超时返回的 202 和任务 ID 未得到处理。
- 健康检查依赖未受 Git 跟踪的 `models/` 目录，新增测试在无模型的 CI 环境会失败；模型标签的清洗覆盖最终导出，渐进转写回调仍将原文交给 Web。
- 截至规划阶段，`git diff --check` 通过。尚未运行测试或真实推理，业务文件没有编辑。

### 修复与验收

- 本机路径读取仅允许真实回环，任务借用源媒体，删除时保留它。服务端入队前拒绝无效轻量参数。同步仅等转写，使用单调截止时间，超时续查同一任务。健康检查读取配置的 SQLite 任务表，失败返回 503。
- 客户端按块上传，遇到不确定的上传结果查询原凭证，轮询按转写状态。收到同步 202 时续查，格式缺失时保留已有输出。拒绝自动重定向，本机回环直连。更新 README 和接口文档。
- 已知 SenseVoice 标记改在模型结果返回后清理，防止它们进入切段、时间戳和实时文本。正文占位符仍会保留。
- 新接口用例在修复前复现 11 个失败，同步时限和客户端等回归另经失败到通过验证。最终用项目虚拟环境的 Python 3.12 加载临时测试依赖，执行 `python -m pytest -q`，404 个测试通过。旧启动器用例改为复制可独立启动的基础解释器。旧 Web 测试用专属应用状态隔离 fixture，避免 pytest 对动态属性的还原冲突。
- 隔离运行真实 HTTP 与本机 FunASR。中文 WAV 走本机路径、fast 生成 1 条带时间戳的字幕；同音轨 MP4 走分块 HTTP 上传、balanced 生成 3 条。两者均为非空中文 SRT 且无模型标记，无音轨 MP4 返回 400。真实样本用于验证接口和产物，未评估识别准确率或长视频负载。
- 最终静态复核指出的自动跳转、系统代理、显式空表单参数和等待截止时间均已修复并纳入回归。当前未运行远端 CI。
